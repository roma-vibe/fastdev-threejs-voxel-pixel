# Three.js Voxel Game, Pixel Style

A browser voxel action-adventure starter in a blocky pixel-art style: procedural pixel textures and character skins, an animated third-person character, Three.js rendering, PixiJS HUD and Vue menus. A small original demo covers exploration, combat, block editing, checkpoints and local saves, with quality checks and optional Docker workflows.

This repository is a [fastDev](https://github.com/roma-vibe/fastDev) project skeleton (`threejs-voxel-pixel`). fastDev lists it
from a registry, downloads it when first used and creates named, ready-to-run projects from it.

- `template.toml` — the manifest: requirements, options, env, setup steps and commands.
- `files/` — the files of a new project (`*.tmpl` files are rendered with the project name and options).
- `CHANGELOG.md` — what changed in every version.

Versions are the `vX.Y.Z` tags of this repository and never change once published.
